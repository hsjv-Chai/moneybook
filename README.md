# 记账本 MoneyBook

一个本地优先的 macOS 个人记账应用：**SwiftUI + SwiftData + Swift Charts**，中文界面，零第三方依赖，不联网、不上传任何数据。

## 功能

- **概览**：本月/上月/近三月/今年/自定义时间范围，收入·支出·结余·总资产四张卡片，近 6 个月收支柱状图、支出构成环形图、最近流水。
- **流水**：原生表格展示明细，可按时间范围、账户、类型、分类筛选，也可按备注/分类/账户搜索；右键菜单编辑删除，选中后按 Delete 删除，双击行编辑。
- **账户**：账户余额与总资产汇总，支持新增/编辑/归档账户，支持账户之间转账（转出转入余额同步变化，净资产不变）。
- **合并流水（AA 对账）**：在流水页选中多笔记录合并成一条净额流水，原记录可一键还原（见下节）。
- **统计**：月度收支趋势（6/12/24 个月）、分类排行与占比、账户余额分布。
- **账单导入**：直接导入微信支付（xlsx / CSV / 由账单生成的 PDF）与支付宝（CSV）账单，自动建立账户、按商户与平台分类自动归类、跳过重复记录并提示疑似重复，可整批撤销（见下节）。
- **设置**：默认记账账户、已归档显示开关、分类管理（图标与配色）、数据库位置定位与清空数据。

金额全程使用 `Decimal`，统一保留两位小数，不使用浮点数。

## 环境要求

- macOS 14 或更高版本（SwiftData 与 `SectorMark` 的下限）
- Xcode（含命令行工具）。若 `xcode-select` 指向 CommandLineTools 而非 Xcode.app，运行脚本会自动显式指定 `DEVELOPER_DIR`

## 运行

```bash
./script/build_and_run.sh            # 构建并启动应用
./script/build_and_run.sh --test     # 运行单元测试
./script/build_and_run.sh --selftest # 无界面自检（校验数据层是否正常）
./script/build_and_run.sh --logs     # 启动并跟踪应用日志
./script/build_and_run.sh --telemetry # 启动并按子系统过滤日志
./script/build_and_run.sh --verify   # 启动并确认进程存活
./script/build_and_run.sh --debug    # 在 lldb 下启动
./script/build_and_run.sh --icon     # 重新生成应用图标（绘制 + 打包 .icns）

# 账单相关的无界面命令（不打开窗口）
./script/build_and_run.sh --selftest                    # 数据层自检
<可执行文件> --check-store                              # 打印当前数据库统计
<可执行文件> --import-preview <账单文件>                 # 只解析并打印结果，不写库
<可执行文件> --import-apply <账单文件>                   # 按默认选项直接导入
```

脚本会把可执行文件打包成 `dist/MoneyBook.app` 后再用 `open` 启动，因此应用拥有正常的 Dock 图标、窗口与菜单栏行为。

> 说明：脚本内部固化了三处构建环境设置——显式 `DEVELOPER_DIR`、把 SwiftPM 缓存重定向到项目内 `.build/`（避免写入 `$HOME` 下的缓存目录）、以及 `--disable-sandbox`（在受限环境中 SwiftPM 自身的沙箱会失败）。

## 数据

数据库为 SwiftData 生成的 SQLite 文件：

```
~/Library/Application Support/MoneyBook/MoneyBook.store
```

可通过环境变量 `MONEYBOOK_DATA_DIR` 覆盖存放目录（测试与自检用）。应用内「设置 → 数据」可以定位文件、查看统计、清空数据。

## 导入账单

入口：工具栏「记一笔」菜单里的「导入微信账单…」，或 `⌘I`。支持微信支付与支付宝两家账单，导入时自动识别来源。

支持的文件形态：

| 来源 | 说明 |
| --- | --- |
| 账单 xlsx | 微信「账单流水文件」导出（当前默认格式）。用系统 Compression 解 ZIP、再解 XML 得到单元格，数据精确；交易时间是 Excel 序列号，按账单声明的 UTC+08:00 还原。 |
| 账单 CSV | 微信「账单下载 → 用于个人对账」的 CSV（UTF-8）与支付宝「交易明细」导出的 CSV（GB18030，前言为 CRLF），按列名解析，数据精确。 |
| 账单 PDF | 把账单另存/打印成的 PDF。这类文件的内嵌字体往往没有可用的 ToUnicode 映射，直接抽取文本会得到乱码，所以走画面文字识别（Vision）后按表格网格重建行列。 |

两家平台的差异已经分别适配：

| | 微信支付 | 支付宝 |
| --- | --- | --- |
| 表头列名 | 交易类型 / 商品 / 支付方式 / 交易单号 | 交易分类 / 商品说明 / 收付款方式 / 交易订单号 |
| 中性交易 | 「中性交易」（充值、提现、信用卡还款等） | 「不计收支」 |
| 资金账户 | 零钱 → 微信零钱、零钱通、理财通 | 账户余额 → 支付宝余额、余额宝、花呗；`账户余额&红包` 这类叠加优惠只取主支付方式 |
| 分类依据 | 交易类型 + 交易对方 + 商品关键词 | 优先使用账单自带的「交易分类」（餐饮美食、交通出行、日用百货…） |

导入流程与规则：

- 导入前先给出预览：来源、笔数、时间范围、收支与转账合计、账户对应关系、逐行明细，以及所有警告。
- 支付方式自动对应账户：`零钱 → 微信零钱`、`零钱通 → 微信零钱通`、`理财通 → 微信理财通`，银行卡按原名建立；已存在的账户会自动匹配，也可以在预览里手动指定或改为新建。
- 中性交易（零钱充值 / 零钱提现 / 信用卡还款 / 理财通买卖）导入为**账户间转账**，不计入收支。
- 分类按商户关键词自动匹配（餐饮 / 交通 / 购物 / 居住 / 娱乐 / 医疗 / 学习 / 通讯），匹配不到时使用你设置的默认分类。
- 退款、已关闭、失败的记录默认跳过，可在预览里开启导入。
- 按交易单号去重：同一份账单重复导入不会产生重复流水。
- 与已有手工记录相比，金额相同、时间相差不超过一天的会给出「疑似重复」提示（手工记录没有单号，无法自动判重）。
- 导入完成后可以「撤销本次导入」，会删除这一批流水，并回收为此新建且没有其他流水的账户。

准确性提示：xlsx 与 CSV 是精确解析；PDF 走文字识别，金额与商户名可能出错。三种来源都会用**账单自带的汇总**（共 N 笔、收入 / 支出 / 中性交易合计）交叉校验解析结果，差异超过 1% 会明确提示，请在预览页核对后再导入。

## 合并流水（AA 对账）

典型场景：聚餐你先付了 ¥300，两位朋友各转回 ¥100。三笔流水都在账上，但餐费实际只花了 ¥100。

用法：在**流水**页用 `⌘`/`⇧` 选中多笔记录 → 工具栏「合并所选」或右键「合并所选（N 笔）…」→ 在浮层里确认日期、分类、账户、说明后合并。

规则：

- **金额取净额**：支出为负、收入为正求和，符号决定结果是支出还是收入（上例为支出 ¥100）。
- **默认值**：分类与账户沿用所选里金额最大那一笔，日期取最早一笔，说明取第一条非空备注；都可以在浮层里改。
- **不支持转账**：转账不影响收支净额，选中里含转账会被拒绝；净额为 0 也无法合并。
- **可撤销**：合并结果上保留了原流水快照，浮层里可直接「撤销合并」，之后也能在流水页右键该条记录撤销，重启后依然有效。
- **不破坏去重**：被合并掉的原始交易单号仍算「已导入」，重新导入同一份账单不会重复入账。
- 合并结果在备注列会显示「合并 N 笔」标记。

## 应用图标

图标由 `script/make_app_icon.swift` 用 Core Graphics 绘制，遵循 Apple 的 macOS 图标规范：

- 1024×1024 画布，圆角矩形主体 824×824（四周各留 100pt）
- 连续圆角（超椭圆）轮廓，而非普通圆角
- 背景不透明、单一光源、柔和投影，内容不触边，16pt 下仍可辨认
- 输出 16/32/128/256/512 的 1x 与 2x，用 `iconutil` 打包为 `Resources/AppIcon.icns`

重新生成：

```bash
./script/build_and_run.sh --icon
```

构建脚本会把 `Resources/AppIcon.icns` 复制进应用包并写入 `CFBundleIconFile`。

## 测试覆盖

`swift test` 覆盖余额累加、转账对净资产的影响、输入校验、归档与删除保护、跨月/跨年归属、空数据、金额精度、筛选组合、种子数据幂等、清空数据，以及磁盘数据库重开后数据仍在；另有一项 5000 笔流水下的月度汇总性能冒烟测试。

## 未包含

预算、周期账单提醒、CSV 导入导出、多币种、标签、小票附件、菜单栏常驻、全局快捷键、iOS 端与任何联网能力。
